# LabConnect

Les produits Bluetooth sont maintenus dans deux dépôts indépendants :

- [LabConnect Bluetooth](https://github.com/Heatmynuts/LabConnect-Bluetooth) :
  firmwares M5Stack ATOM Lite SPP/BLE et clavier HID ;
- [LabConnect Key pour macOS](https://github.com/Heatmynuts/LabConnect-Key-macOS) :
  réception des pesées par BLE ou câble RS-232/USB et saisie automatique.

L’ancienne branche `codex/LabconnectKey` est conservée temporairement comme
archive de migration. Les développements actifs se font dans les deux dépôts
ci-dessus.
